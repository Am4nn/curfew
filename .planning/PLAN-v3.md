# PLAN-v3.md — superseded

The v3 scope was reworked in September 2026 and now lives in `.planning/v3/`. Start
with `v3/SCOPE.md`, which indexes the rest.

| File | Covers |
|---|---|
| `v3/SCOPE.md` | The reframe, what ships, what does not, the decision log, invariants |
| `v3/ACTIVITIES.md` | Activity model, periods, streaks, grace, pass tests, catalog, extensibility |
| `v3/EVIDENCE.md` | Photo capture, camera UI, storage, retention |
| `v3/REPUTATION.md` | The 0 to 1000 score, its curve, breadth, decay, rebuildability |
| `v3/RANKS.md` | DOUBT to IMMACULATE, bands, colors, icons |
| `v3/GROUPS.md` | Accepted types, sharing, money toggle, evidence view, leaving |
| `v3/UX.md` | Five-tab navigation, Home vs Activities, visual language |
| `v3/TRUST-SAFETY.md` | Consent, policies, moderation, deletion, the security round |
| `v3/ARCHITECTURE.md` | Runtime, schema, the module spec, scoring jobs, uploads, testing |
| `v3/CONFIG.md` | The module registry, app settings, the sync script, caching |
| `v3/SCREENS.md` | Every artboard, its route, and the review gate |
| `v3/PLAN.md` | The nine build phases |

What the old plan said and the new set changes:

- Money is no longer framed as a per-group opt-in bolted onto a fixed catalog. It
  is a group toggle over fully customizable per-user activities.
- Reputation, ranks and photo evidence did not exist in the old plan and are now
  central.
- Steps stays in, with optional gallery evidence, rather than being the weak link.
- Migration is a fresh start, not a carry-over.
